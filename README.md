# masters-lenses

六個由使用者呼叫的工程協作 skill。用不同的關注優先序協助討論、規劃、實作與檢討；使用者決定要用哪個面向，也可以請模型推薦。

[取得 ZIP](dist/masters-lenses.zip)

## 使用

安裝後可用以下方式指定面向；也可以提供具體 SKILL.md 路徑，請模型讀取並使用該份內容。

| 呼叫 | 用途 | 請求例子 |
|---|---|---|
| `$design` | 系統因果 | 檢查這項上游選擇會讓哪些下游成本改變。 |
| `$feedback` | 回饋迴路 | 哪一步最能區分目前的兩個假設？何時足以停止？ |
| `$evolve` | 變更能力 | 檢查這次需求會讓哪些知識必須一起改動。 |
| `$simplicity` | 必要複雜度 | 檢查這些層次是否都在表達必要行為。 |
| `$reliability` | 狀態正確性 | 檢查中斷與重試後，哪些承諾仍然成立。 |
| `$performance` | 執行成本 | 根據量測比較目前值得優化的路徑。 |

提供當前目標、相關材料及已接受限制即可。可要求多個面向，但不預設每次全用；相同模型切換視角不構成獨立驗證。沒有實質新增觀察時允許直接說明。

## 取用

ZIP 內包含六個以呼叫名稱命名的資料夾，可單獨取用。每份都包含完整提示詞與介面設定，無須安裝其餘五份。

六個 skill 都設定為由你明確呼叫。安裝前請確認名稱不會覆蓋既有 skill。

需要修改提示詞或重建成品時，請看 [維護說明](MAINTENANCE.md)。
